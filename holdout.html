No-retuning benchmark test

The validation result changes the structural claim—not the old parameters.

What survived

The frozen model improves RMSE relative to persistence, so renewable-capacity intensity contains useful information about the direction of fossil-dependency change.

What did not survive

The training-selected static clean-competition model has lower holdout RMSE than the selected dynamic model. Therefore the specific three-year lag should not be promoted as a robust parameter estimate.

Systematic residual

All eight errors are positive. The model underestimates the observed post-2017 decline rather than missing through random year-to-year noise.

COVID is not the explanation

Removing 2020 without refitting changes frozen-model RMSE only from 0.01373 to 0.01367. The structural discrepancy persists.
