External reference guardrails

Reference data are used to test scale—not to disguise calibration.

Global Carbon Budget 2025

The 2025 fossil-CO₂ benchmark is about 10.4 GtC/yr (38.1 GtCO₂/yr). The Structural reference is initialized to reproduce this current fossil-flow scale.

Global Carbon Budget 2025 ↗

IEA Current Policies Scenario

IEA WEO 2025 keeps global energy-related CO₂ near 40 GtCO₂/yr through 2050. This is used only as an external order-of-magnitude guardrail because its accounting boundary differs from the Global Carbon Budget fossil-CO₂ boundary.

IEA Current Policies Scenario ↗

Interpretation rule

The IEA explicitly states that CPS is not a forecast, prediction, or “business-as-usual” scenario. This project therefore uses the term Structural reference and does not fit its default trajectory to CPS.

Scope comparison

This project is intentionally not another EN‑ROADS or EPS.

Carbon Beyond the Bathtub

  • Narrow question: why fossil-carbon mobilization persists.
  • Explicit extraction → inventory → combustion/product pathway.
  • Focus on lock-in, investment, capital turnover, capability, and institutional resistance.
  • Educational carbon-cycle shell plus research-hypothesis upstream model.
  • Currently uncalibrated; no temperature or economy-wide cost outputs.

EN‑ROADS

EN‑ROADS is a globally aggregated system-dynamics model spanning energy, economy, land use, agriculture, greenhouse gases, and climate. Its technical reference documents calibration to extensive historical data and a much broader endogenous energy/climate system.

Official technical reference ↗

Energy Policy Simulator

EPS is a free, open-source policy model covering major economy sectors including transportation, electricity, buildings, industry, agriculture, and land use, with policy, financial, and public-health outputs. This project does not attempt that sectoral breadth.

Official EPS documentation ↗
Positioning: the contribution being explored here is not breadth. It is a transparent, inspectable chain from historical lock-in and upstream investment to fossil extraction and atmospheric carbon, suitable for teaching and for developing testable research hypotheses.
